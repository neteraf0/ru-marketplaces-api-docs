## Endpoints

- [`POST` /api/v3/supplies](POST__api_v3_supplies.md) — Create a New Supply
- [`GET` /api/v3/supplies](GET__api_v3_supplies.md) — Get a Supplies List
- [`PATCH` /api/marketplace/v3/supplies/{supplyId}/orders](PATCH__api_marketplace_v3_supplies__supplyId__orders.md) — Add Assembly Orders to the Supply
- [`GET` /api/v3/supplies/{supplyId}](GET__api_v3_supplies__supplyId.md) — Get Supply Details
- [`DELETE` /api/v3/supplies/{supplyId}](DELETE__api_v3_supplies__supplyId.md) — Delete the Supply
- [`GET` /api/marketplace/v3/supplies/{supplyId}/order-ids](GET__api_marketplace_v3_supplies__supplyId__order_ids.md) — Get Supply Assembly Order IDs
- [`PATCH` /api/v3/supplies/{supplyId}/deliver](PATCH__api_v3_supplies__supplyId__deliver.md) — Move the Supply to the Delivery
- [`GET` /api/v3/supplies/{supplyId}/barcode](GET__api_v3_supplies__supplyId__barcode.md) — Get the Supply QR Code
- [`GET` /api/v3/supplies/{supplyId}/trbx](GET__api_v3_supplies__supplyId__trbx.md) — Get Supply Shipping Units List
- [`POST` /api/v3/supplies/{supplyId}/trbx](POST__api_v3_supplies__supplyId__trbx.md) — Add Shipping Units to the Supply
- [`DELETE` /api/v3/supplies/{supplyId}/trbx](DELETE__api_v3_supplies__supplyId__trbx.md) — Delete Shipping Units from the Supply
- [`POST` /api/v3/supplies/{supplyId}/trbx/stickers](POST__api_v3_supplies__supplyId__trbx_stickers.md) — Get the Supply Shipping Unit QR Code Stickers
