## Endpoints

- [`POST` /api/marketplace/v3/click-collect/orders/meta/info](POST__api_marketplace_v3_click_collect_orders_meta_info.md) — Get Assembly Orders Metadata
- [`POST` /api/marketplace/v3/click-collect/orders/meta/delete](POST__api_marketplace_v3_click_collect_orders_meta_delete.md) — Delete Assembly Order Metadata
- [`POST` /api/marketplace/v3/click-collect/orders/meta/sgtin](POST__api_marketplace_v3_click_collect_orders_meta_sgtin.md) — Add Labeling codes Chestny ZNAK to the Assembly Orders (Chestny ZNAK)
- [`POST` /api/marketplace/v3/click-collect/orders/meta/uin](POST__api_marketplace_v3_click_collect_orders_meta_uin.md) — Add UIN (Unique Identification Numbers) to the Assembly Orders
- [`POST` /api/marketplace/v3/click-collect/orders/meta/imei](POST__api_marketplace_v3_click_collect_orders_meta_imei.md) — Add IMEI to the Assembly Orders
- [`POST` /api/marketplace/v3/click-collect/orders/meta/gtin](POST__api_marketplace_v3_click_collect_orders_meta_gtin.md) — Add GTIN to the Assembly Orders
- [`GET` /api/v3/click-collect/orders/{orderId}/meta](GET__api_v3_click_collect_orders__orderId__meta.md) — Get Assembly Order Metadata
- [`DELETE` /api/v3/click-collect/orders/{orderId}/meta](DELETE__api_v3_click_collect_orders__orderId__meta.md) — Delete Assembly Order Metadata
- [`PUT` /api/v3/click-collect/orders/{orderId}/meta/sgtin](PUT__api_v3_click_collect_orders__orderId__meta_sgtin.md) — Assign a Data Matrix Code to the Assembly Order
- [`PUT` /api/v3/click-collect/orders/{orderId}/meta/uin](PUT__api_v3_click_collect_orders__orderId__meta_uin.md) — Add UIN (Unique Identification Number) to the Assembly Order
- [`PUT` /api/v3/click-collect/orders/{orderId}/meta/imei](PUT__api_v3_click_collect_orders__orderId__meta_imei.md) — Add IMEI to the Assembly Order
- [`PUT` /api/v3/click-collect/orders/{orderId}/meta/gtin](PUT__api_v3_click_collect_orders__orderId__meta_gtin.md) — Add GTIN to the Assembly Order
