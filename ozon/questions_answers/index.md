# Questions&Answers

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/question/answer/create](POST__v1_question_answer_create.md) — Создать ответ на вопрос
- [`POST` /v1/question/answer/delete](POST__v1_question_answer_delete.md) — Удалить ответ на вопрос
- [`POST` /v1/question/answer/list](POST__v1_question_answer_list.md) — Список ответов на вопрос
- [`POST` /v1/question/change-status](POST__v1_question_change_status.md) — Изменить статус вопросов
- [`POST` /v1/question/count](POST__v1_question_count.md) — Количество вопросов по статусам
- [`POST` /v1/question/info](POST__v1_question_info.md) — Информация о вопросе
- [`POST` /v1/question/list](POST__v1_question_list.md) — Список вопросов
- [`POST` /v1/question/top-sku](POST__v1_question_top_sku.md) — Товары с наибольшим количеством вопросов
