# WarehouseAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/warehouse/list](POST__v1_warehouse_list.md) — Список складов
- [`POST` /v1/delivery-method/list](POST__v1_delivery_method_list.md) — Список методов доставки склада
- [`POST` /v2/delivery-method/list](POST__v2_delivery_method_list.md) — Список методов доставки realFBS-склада
- [`POST` /v1/delivery-method/return/settings/get](POST__v1_delivery_method_return_settings_get.md) — Получить информацию по возвратным настройкам rFBS и rFBS Express
- [`POST` /v2/warehouse/list](POST__v2_warehouse_list.md) — Список складов
- [`POST` /v1/warehouse/operation/status](POST__v1_warehouse_operation_status.md) — Получить статус операции
- [`POST` /v1/warehouse/archive](POST__v1_warehouse_archive.md) — Перенести склад в архив
- [`POST` /v1/warehouse/unarchive](POST__v1_warehouse_unarchive.md) — Перенести склад из архива
- [`POST` /v1/warehouse/invalid-products/get](POST__v1_warehouse_invalid_products_get.md) — Получить список товаров с ограничениями по доставке
- [`POST` /v1/warehouse/warehouses-with-invalid-products](POST__v1_warehouse_warehouses_with_invalid_products.md) — Получить список складов с ограниченными для доставки товарами
