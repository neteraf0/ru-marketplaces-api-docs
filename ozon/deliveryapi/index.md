# DeliveryAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/delivery/check](POST__v1_delivery_check.md) — Проверить доступность доставки для покупателя
- [`POST` /v2/delivery/checkout](POST__v2_delivery_checkout.md) — Получить доступные варианты доставки
- [`POST` /v1/delivery/map](POST__v1_delivery_map.md) — Отрисовать точки на карте
- [`POST` /v1/delivery/point/info](POST__v1_delivery_point_info.md) — Получить информацию о точке самовывоза
- [`POST` /v1/delivery/point/list](POST__v1_delivery_point_list.md) — Получить список точек самовывоза
