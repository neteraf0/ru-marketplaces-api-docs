# OrderDirectFBP

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/fbp/order/direct/cancel](POST__v1_fbp_order_direct_cancel.md) — Отменить поставку
- [`POST` /v1/fbp/order/direct/seller-dlv/edit](POST__v1_fbp_order_direct_seller_dlv_edit.md) — Обновить информацию о доставке силами продавца
- [`POST` /v1/fbp/order/direct/timeslot/edit](POST__v1_fbp_order_direct_timeslot_edit.md) — Отредактировать таймслот в заявке на поставку
- [`POST` /v1/fbp/order/direct/timeslot/list](POST__v1_fbp_order_direct_timeslot_list.md) — Получить список таймслотов для поставки
