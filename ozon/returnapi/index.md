# ReturnAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/returns/company/fbs/info](POST__v1_returns_company_fbs_info.md) — Количество возвратов FBS
- [`POST` /v1/return/giveout/is-enabled](POST__v1_return_giveout_is_enabled.md) — Проверить возможность получения возвратных отгрузок по штрихкоду
- [`POST` /v1/return/giveout/list](POST__v1_return_giveout_list.md) — Список возвратных отгрузок
- [`POST` /v1/return/giveout/info](POST__v1_return_giveout_info.md) — Информация о возвратной отгрузке
- [`POST` /v1/return/giveout/barcode](POST__v1_return_giveout_barcode.md) — Значение штрихкода для возвратных отгрузок
- [`POST` /v1/return/giveout/get-pdf](POST__v1_return_giveout_get_pdf.md) — Штрихкод для получения возвратной отгрузки в формате PDF
- [`POST` /v1/return/giveout/get-png](POST__v1_return_giveout_get_png.md) — Штрихкод для получения возвратной отгрузки в формате PNG
- [`POST` /v1/return/giveout/barcode-reset](POST__v1_return_giveout_barcode_reset.md) — Сгенерировать новый штрихкод
