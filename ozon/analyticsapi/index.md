# AnalyticsAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v2/analytics/stock_on_warehouses](POST__v2_analytics_stock_on_warehouses.md) — Отчёт по остаткам и товарам
- [`POST` /v1/analytics/turnover/stocks](POST__v1_analytics_turnover_stocks.md) — Оборачиваемость товара
- [`POST` /v1/analytics/average-delivery-time](POST__v1_analytics_average_delivery_time.md) — Получить аналитику по среднему времени доставки
- [`POST` /v1/analytics/average-delivery-time/details](POST__v1_analytics_average_delivery_time_details.md) — Получить детальную аналитику по среднему времени доставки
- [`POST` /v1/analytics/average-delivery-time/summary](POST__v1_analytics_average_delivery_time_summary.md) — Получить общую аналитику по среднему времени доставки
- [`POST` /v1/analytics/stocks](POST__v1_analytics_stocks.md) — Получить аналитику по остаткам
