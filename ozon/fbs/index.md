## Endpoints

- [`POST` /v3/posting/fbs/unfulfilled/list](POST__v3_posting_fbs_unfulfilled_list.md) — Список необработанных отправлений
- [`POST` /v4/posting/fbs/unfulfilled/list](POST__v4_posting_fbs_unfulfilled_list.md) — Получить список необработанных отправлений
- [`POST` /v3/posting/fbs/list](POST__v3_posting_fbs_list.md) — Список отправлений

- [`POST` /v3/posting/fbs/get](POST__v3_posting_fbs_get.md) — Получить информацию об отправлении по идентификатору
- [`POST` /v2/posting/fbs/get-by-barcode](POST__v2_posting_fbs_get_by_barcode.md) — Получить информацию об отправлении по штрихкоду
- [`POST` /v3/posting/multiboxqty/set](POST__v3_posting_multiboxqty_set.md) — Указать количество коробок для многокоробочных отправлений
- [`POST` /v2/posting/fbs/product/country/list](POST__v2_posting_fbs_product_country_list.md) — Список доступных стран-изготовителей
- [`POST` /v2/posting/fbs/product/country/set](POST__v2_posting_fbs_product_country_set.md) — Добавить информацию о стране-изготовителе товара
- [`POST` /v1/posting/fbs/restrictions](POST__v1_posting_fbs_restrictions.md) — Получить ограничения пункта приёма
- [`POST` /v2/posting/fbs/package-label](POST__v2_posting_fbs_package_label.md) — Напечатать этикетку
- [`POST` /v1/posting/fbs/package-label/create](POST__v1_posting_fbs_package_label_create.md) — Создать задание на выгрузку этикеток
- [`POST` /v2/posting/fbs/package-label/create](POST__v2_posting_fbs_package_label_create.md) — Создать задание на формирование этикеток
- [`POST` /v1/posting/fbs/package-label/get](POST__v1_posting_fbs_package_label_get.md) — Получить файл с этикетками
- [`POST` /v1/posting/fbs/cancel-reason](POST__v1_posting_fbs_cancel_reason.md) — Причины отмены отправления
- [`POST` /v2/posting/fbs/cancel-reason/list](POST__v2_posting_fbs_cancel_reason_list.md) — Причины отмены отправлений
- [`POST` /v2/posting/fbs/product/cancel](POST__v2_posting_fbs_product_cancel.md) — Отменить отправку некоторых товаров в отправлении
- [`POST` /v2/posting/fbs/cancel](POST__v2_posting_fbs_cancel.md) — Отменить отправление
- [`POST` /v2/posting/fbs/arbitration](POST__v2_posting_fbs_arbitration.md) — Открыть спор по отправлению
- [`POST` /v2/posting/fbs/awaiting-delivery](POST__v2_posting_fbs_awaiting_delivery.md) — Передать отправление к отгрузке
- [`POST` /v1/posting/fbs/pick-up-code/verify](POST__v1_posting_fbs_pick_up_code_verify.md) — Проверить код курьера
- [`POST` /v1/posting/global/etgb](POST__v1_posting_global_etgb.md) — Таможенные декларации ETGB
- [`POST` /v1/posting/unpaid-legal/product/list](POST__v1_posting_unpaid_legal_product_list.md) — Список неоплаченных товаров, заказанных юридическими лицами
