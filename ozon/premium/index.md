## Endpoints

- [`POST` /v1/chat/send/message](POST__v1_chat_send_message.md) — Отправить сообщение
- [`POST` /v1/chat/start](POST__v1_chat_start.md) — Создать новый чат
- [`POST` /v2/chat/read](POST__v2_chat_read.md) — Отметить сообщения как прочитанные
- [`POST` /v1/analytics/data](POST__v1_analytics_data.md) — Данные аналитики
- [`POST` /v1/analytics/product-queries](POST__v1_analytics_product_queries.md) — Получить информацию о запросах моих товаров
- [`POST` /v1/analytics/product-queries/details](POST__v1_analytics_product_queries_details.md) — Получить детализацию запросов по товару
- [`POST` /v1/finance/realization/by-day](POST__v1_finance_realization_by_day.md) — Отчёт о реализации товаров за день
- [`POST` /v1/search-queries/text](POST__v1_search_queries_text.md) — Получить список поисковых запросов по тексту
- [`POST` /v1/search-queries/top](POST__v1_search_queries_top.md) — Получить список популярных поисковых запросов
- [`POST` /v1/product/prices/details](POST__v1_product_prices_details.md) — Получить подробную информацию о ценах товаров
