# ProductAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v3/product/import](POST__v3_product_import.md) — Создать или обновить товар
- [`POST` /v1/product/import/info](POST__v1_product_import_info.md) — Узнать статус добавления или обновления товара
- [`POST` /v1/product/import-by-sku](POST__v1_product_import_by_sku.md) — Создать товар по SKU
- [`POST` /v1/product/attributes/update](POST__v1_product_attributes_update.md) — Обновить характеристики товара
- [`POST` /v1/product/pictures/import](POST__v1_product_pictures_import.md) — Загрузить или обновить изображения товара
- [`POST` /v3/product/list](POST__v3_product_list.md) — Список товаров
- [`POST` /v1/product/rating-by-sku](POST__v1_product_rating_by_sku.md) — Получить контент-рейтинг товаров по SKU
- [`POST` /v3/product/info/list](POST__v3_product_info_list.md) — Получить информацию о товарах по идентификаторам
- [`POST` /v4/product/info/attributes](POST__v4_product_info_attributes.md) — Получить описание характеристик товара
- [`POST` /v1/product/info/description](POST__v1_product_info_description.md) — Получить описание товара
- [`POST` /v4/product/info/limit](POST__v4_product_info_limit.md) — Лимиты на ассортимент, создание и обновление товаров
- [`POST` /v1/product/update/offer-id](POST__v1_product_update_offer_id.md) — Изменить артикулы товаров из системы продавца
- [`POST` /v1/product/archive](POST__v1_product_archive.md) — Перенести товар в архив
- [`POST` /v1/product/unarchive](POST__v1_product_unarchive.md) — Вернуть товар из архива
- [`POST` /v2/products/delete](POST__v2_products_delete.md) — Удалить товар без SKU из архива
- [`POST` /v1/product/info/subscription](POST__v1_product_info_subscription.md) — Количество подписавшихся на товар пользователей
- [`POST` /v1/product/related-sku/get](POST__v1_product_related_sku_get.md) — Получить связанные SKU
- [`POST` /v2/product/pictures/info](POST__v2_product_pictures_info.md) — Получить изображения товаров
- [`POST` /v1/product/info/wrong-volume](POST__v1_product_info_wrong_volume.md) — Список товаров с некорректными ОВХ
- [`POST` /v1/product/placement-zone/info](POST__v1_product_placement_zone_info.md) — Получить зоны размещения товаров по SKU перед поставкой
