# Promos

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`GET` /v1/actions](GET__v1_actions.md) — Список акций
- [`POST` /v1/actions/candidates](POST__v1_actions_candidates.md) — Список доступных для акции товаров
- [`POST` /v1/actions/products](POST__v1_actions_products.md) — Список участвующих в акции товаров
- [`POST` /v1/actions/products/activate](POST__v1_actions_products_activate.md) — Добавить товар в акцию
- [`POST` /v1/actions/products/deactivate](POST__v1_actions_products_deactivate.md) — Удалить товары из акции
- [`POST` /v1/actions/discounts-task/list](POST__v1_actions_discounts_task_list.md) — Список заявок на скидку
- [`POST` /v1/actions/discounts-task/approve](POST__v1_actions_discounts_task_approve.md) — Согласовать заявку на скидку
- [`POST` /v1/actions/discounts-task/decline](POST__v1_actions_discounts_task_decline.md) — Отклонить заявку на скидку
