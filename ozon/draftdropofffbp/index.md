# DraftDropOffFBP

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/fbp/draft/drop-off/create](POST__v1_fbp_draft_drop_off_create.md) — Создать черновик для доставки в drop-off пункт
- [`POST` /v1/fbp/draft/drop-off/delete](POST__v1_fbp_draft_drop_off_delete.md) — Удалить черновик для доставки в drop-off пункт
- [`POST` /v1/fbp/draft/drop-off/dlv/edit](POST__v1_fbp_draft_drop_off_dlv_edit.md) — Отредактировать детали доставки для drop-off черновика
- [`POST` /v1/fbp/draft/drop-off/registrate](POST__v1_fbp_draft_drop_off_registrate.md) — Перевести черновик в действующую поставку
- [`POST` /v1/fbp/draft/drop-off/province/list](POST__v1_fbp_draft_drop_off_province_list.md) — Получить список провинций
- [`POST` /v1/fbp/draft/drop-off/point/list](POST__v1_fbp_draft_drop_off_point_list.md) — Получить список drop-off пунктов в провинции
- [`POST` /v1/fbp/draft/drop-off/point/timetable](POST__v1_fbp_draft_drop_off_point_timetable.md) — Получить расписание работы drop-off пункта
- [`POST` /v1/fbp/draft/drop-off/product/validate](POST__v1_fbp_draft_drop_off_product_validate.md) — Проверить список товаров, которые склад партнёра может принять
