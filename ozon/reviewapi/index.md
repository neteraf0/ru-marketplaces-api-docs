# ReviewAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/review/comment/create](POST__v1_review_comment_create.md) — Оставить комментарий на отзыв
- [`POST` /v1/review/comment/delete](POST__v1_review_comment_delete.md) — Удалить комментарий на отзыв
- [`POST` /v2/review/comment/delete](POST__v2_review_comment_delete.md) — Удалить комментарий на отзыв
- [`POST` /v1/review/comment/list](POST__v1_review_comment_list.md) — Получить список комментариев на отзыв
- [`POST` /v1/review/change-status](POST__v1_review_change_status.md) — Изменить статус отзывов
- [`POST` /v2/review/change-status](POST__v2_review_change_status.md) — Изменить статус отзывов
- [`POST` /v1/review/count](POST__v1_review_count.md) — Количество отзывов по статусам
- [`POST` /v2/review/count](POST__v2_review_count.md) — Получить количество отзывов по статусам
- [`POST` /v1/review/info](POST__v1_review_info.md) — Получить информацию об отзыве
- [`POST` /v2/review/info](POST__v2_review_info.md) — Получить информацию по отзыву
- [`POST` /v1/review/list](POST__v1_review_list.md) — Получить список отзывов
- [`POST` /v2/review/list](POST__v2_review_list.md) — Получить список отзывов
