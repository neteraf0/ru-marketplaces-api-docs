# FinanceAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v2/finance/realization](POST__v2_finance_realization.md) — Отчёт о реализации товаров (версия 2)
- [`POST` /v1/finance/realization/posting](POST__v1_finance_realization_posting.md) — Позаказный отчёт о реализации товаров
- [`POST` /v3/finance/transaction/list](POST__v3_finance_transaction_list.md) — Список транзакций
- [`POST` /v3/finance/transaction/totals](POST__v3_finance_transaction_totals.md) — Суммы транзакций
- [`POST` /v1/finance/document-b2b-sales](POST__v1_finance_document_b2b_sales.md) — Реестр продаж юридическим лицам
- [`POST` /v1/finance/document-b2b-sales/json](POST__v1_finance_document_b2b_sales_json.md) — Реестр продаж юридическим лицам в JSON-формате
- [`POST` /v1/finance/mutual-settlement](POST__v1_finance_mutual_settlement.md) — Отчёт о взаиморасчётах
- [`POST` /v1/finance/products/buyout](POST__v1_finance_products_buyout.md) — Отчёт о выкупленных товарах
- [`POST` /v1/finance/compensation](POST__v1_finance_compensation.md) — Отчёт о компенсациях
- [`POST` /v1/finance/decompensation](POST__v1_finance_decompensation.md) — Отчёт о декомпенсациях
