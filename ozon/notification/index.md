# Notification

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/notification/set](POST__v1_notification_set.md) — Подключить URL-адрес для уведомлений
- [`POST` /v1/notification/update](POST__v1_notification_update.md) — Изменить URL-адрес для уведомлений
- [`POST` /v1/notification/delete](POST__v1_notification_delete.md) — Удалить URL-адрес для уведомлений
- [`POST` /v1/notification/check](POST__v1_notification_check.md) — Проверить URL-адрес для уведомлений
- [`POST` /v1/notification/enable](POST__v1_notification_enable.md) — Включить или выключить уведомления на URL-адрес
- [`POST` /v1/notification/list](POST__v1_notification_list.md) — Получить информацию по подключённым URL-адресам
- [`POST` /v1/notification/push-type/list](POST__v1_notification_push_type_list.md) — Получить типы пуш-уведомлений
