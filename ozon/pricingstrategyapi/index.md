# PricingStrategyAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/pricing-strategy/competitors/list](POST__v1_pricing_strategy_competitors_list.md) — Список конкурентов
- [`POST` /v1/pricing-strategy/list](POST__v1_pricing_strategy_list.md) — Список стратегий
- [`POST` /v1/pricing-strategy/create](POST__v1_pricing_strategy_create.md) — Создать стратегию
- [`POST` /v1/pricing-strategy/info](POST__v1_pricing_strategy_info.md) — Информация о стратегии
- [`POST` /v1/pricing-strategy/update](POST__v1_pricing_strategy_update.md) — Обновить стратегию
- [`POST` /v1/pricing-strategy/products/add](POST__v1_pricing_strategy_products_add.md) — Добавить товары в стратегию
- [`POST` /v1/pricing-strategy/strategy-ids-by-product-ids](POST__v1_pricing_strategy_strategy_ids_by_product_ids.md) — Список идентификаторов стратегий
- [`POST` /v1/pricing-strategy/products/list](POST__v1_pricing_strategy_products_list.md) — Список товаров в стратегии
- [`POST` /v1/pricing-strategy/product/info](POST__v1_pricing_strategy_product_info.md) — Цена товара у конкурента
- [`POST` /v1/pricing-strategy/products/delete](POST__v1_pricing_strategy_products_delete.md) — Удалить товары из стратегии
- [`POST` /v1/pricing-strategy/status](POST__v1_pricing_strategy_status.md) — Изменить статус стратегии
- [`POST` /v1/pricing-strategy/delete](POST__v1_pricing_strategy_delete.md) — Удалить стратегию
