# ReportAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/report/info](POST__v1_report_info.md) — Информация об отчёте
- [`POST` /v1/report/list](POST__v1_report_list.md) — Список отчётов
- [`POST` /v1/report/products/create](POST__v1_report_products_create.md) — Отчёт по товарам
- [`POST` /v2/report/returns/create](POST__v2_report_returns_create.md) — Отчёт о возвратах
- [`POST` /v1/report/postings/create](POST__v1_report_postings_create.md) — Отчёт об отправлениях
- [`POST` /v1/finance/cash-flow-statement/list](POST__v1_finance_cash_flow_statement_list.md) — Финансовый отчёт
- [`POST` /v1/report/discounted/create](POST__v1_report_discounted_create.md) — Отчёт об уценённых товарах
- [`POST` /v1/report/warehouse/stock](POST__v1_report_warehouse_stock.md) — Отчёт об остатках на FBS-складе
- [`POST` /v1/report/placement/by-products/create](POST__v1_report_placement_by_products_create.md) — Получить отчёт о стоимости размещения по товарам
- [`POST` /v1/report/placement/by-supplies/create](POST__v1_report_placement_by_supplies_create.md) — Получить отчёт о стоимости размещения по поставкам
- [`POST` /v1/report/marked-products-sales/create](POST__v1_report_marked_products_sales_create.md) — Сгенерировать отчёт по продажам товаров с маркировкой
