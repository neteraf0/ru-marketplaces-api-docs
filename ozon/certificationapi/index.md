# CertificationAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`GET` /v1/product/certificate/accordance-types](GET__v1_product_certificate_accordance_types.md) — Список типов соответствия требованиям (версия 1)
- [`GET` /v2/product/certificate/accordance-types/list](GET__v2_product_certificate_accordance_types_list.md) — Список типов соответствия требованиям (версия 2)
- [`GET` /v1/product/certificate/types](GET__v1_product_certificate_types.md) — Справочник типов документов
- [`POST` /v2/product/certification/list](POST__v2_product_certification_list.md) — Список сертифицируемых категорий
- [`POST` /v1/product/certification/list](POST__v1_product_certification_list.md) — Список сертифицируемых категорий
- [`POST` /v1/product/certificate/create](POST__v1_product_certificate_create.md) — Добавить сертификаты для товаров
- [`POST` /v1/product/certificate/bind](POST__v1_product_certificate_bind.md) — Привязать сертификат к товару
- [`POST` /v1/product/certificate/delete](POST__v1_product_certificate_delete.md) — Удалить сертификат
- [`POST` /v1/product/certificate/info](POST__v1_product_certificate_info.md) — Информация о сертификате
- [`POST` /v1/product/certificate/list](POST__v1_product_certificate_list.md) — Список сертификатов
- [`POST` /v1/product/certificate/product_status/list](POST__v1_product_certificate_product_status_list.md) — Список возможных статусов товаров
- [`POST` /v1/product/certificate/products/list](POST__v1_product_certificate_products_list.md) — Список товаров, привязанных к сертификату
- [`POST` /v1/product/certificate/unbind](POST__v1_product_certificate_unbind.md) — Отвязать товар от сертификата
- [`POST` /v1/product/certificate/rejection_reasons/list](POST__v1_product_certificate_rejection_reasons_list.md) — Возможные причины отклонения сертификата
- [`POST` /v1/product/certificate/status/list](POST__v1_product_certificate_status_list.md) — Возможные статусы сертификатов
