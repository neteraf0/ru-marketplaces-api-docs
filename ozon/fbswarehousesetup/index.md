## Endpoints

- [`POST` /v1/warehouse/fbs/create/drop-off/list](POST__v1_warehouse_fbs_create_drop_off_list.md) — Получить список drop-off пунктов для создания склада
- [`POST` /v1/warehouse/fbs/update/drop-off/list](POST__v1_warehouse_fbs_update_drop_off_list.md) — Получить список drop-off пунктов для изменения информации склада
- [`POST` /v1/warehouse/fbs/create/drop-off/timeslot/list](POST__v1_warehouse_fbs_create_drop_off_timeslot_list.md) — Получить список таймслотов для создания склада с отгрузкой drop-off
- [`POST` /v1/warehouse/fbs/update/drop-off/timeslot/list](POST__v1_warehouse_fbs_update_drop_off_timeslot_list.md) — Получить список таймслотов для обновления склада с отгрузкой drop-off
- [`POST` /v1/warehouse/fbs/create/pick-up/timeslot/list](POST__v1_warehouse_fbs_create_pick_up_timeslot_list.md) — Получить список таймслотов для создания склада с отгрузкой pick-up
- [`POST` /v1/warehouse/fbs/update/pick-up/timeslot/list](POST__v1_warehouse_fbs_update_pick_up_timeslot_list.md) — Получить список таймслотов для обновления склада с отгрузкой pick-up
- [`POST` /v1/warehouse/fbs/create](POST__v1_warehouse_fbs_create.md) — Создать склад
- [`POST` /v1/warehouse/fbs/update](POST__v1_warehouse_fbs_update.md) — Обновить склад
- [`POST` /v1/warehouse/fbs/first-mile/update](POST__v1_warehouse_fbs_first_mile_update.md) — Обновить первую милю
- [`POST` /v1/warehouse/fbs/create/return-point/list](POST__v1_warehouse_fbs_create_return_point_list.md) — Получить список пунктов возврата для создания склада
- [`POST` /v1/warehouse/fbs/update/return-point/list](POST__v1_warehouse_fbs_update_return_point_list.md) — Получить список пунктов возврата для обновления склада
- [`POST` /v1/warehouse/fbs/return-mile/info](POST__v1_warehouse_fbs_return_mile_info.md) — Получить информацию о возвратной миле
- [`POST` /v1/warehouse/fbs/return-mile/check](POST__v1_warehouse_fbs_return_mile_check.md) — Проверить необходимость установки возвратной мили на склад
- [`POST` /v1/warehouse/fbs/pickup/courier/create](POST__v1_warehouse_fbs_pickup_courier_create.md) — Создать вызов курьера на забор отгрузки pick-up
- [`POST` /v1/warehouse/fbs/pickup/courier/cancel](POST__v1_warehouse_fbs_pickup_courier_cancel.md) — Отменить вызов курьера на забор отгрузки pick-up
- [`POST` /v1/warehouse/fbs/pickup/history/list](POST__v1_warehouse_fbs_pickup_history_list.md) — Получить историю отгрузок курьерам
- [`POST` /v1/warehouse/fbs/pickup/planning/list](POST__v1_warehouse_fbs_pickup_planning_list.md) — Получить список складов для планирования отгрузок курьеру
