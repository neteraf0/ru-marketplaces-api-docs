# FBO

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v2/posting/fbo/list](POST__v2_posting_fbo_list.md) — Список отправлений
- [`POST` /v3/posting/fbo/list](POST__v3_posting_fbo_list.md) — Получить список отправлений
- [`POST` /v2/posting/fbo/get](POST__v2_posting_fbo_get.md) — Информация об отправлении
- [`POST` /v1/posting/fbo/cancel-reason/list](POST__v1_posting_fbo_cancel_reason_list.md) — Причины отмены отправлений по схеме FBO
- [`POST` /v1/supply-order/status/counter](POST__v1_supply_order_status_counter.md) — Количество заявок по статусам
- [`POST` /v1/supply-order/bundle](POST__v1_supply_order_bundle.md) — Состав поставки или заявки на поставку
- [`POST` /v3/supply-order/list](POST__v3_supply_order_list.md) — Список заявок на поставку на склад Ozon
- [`POST` /v3/supply-order/get](POST__v3_supply_order_get.md) — Информация о заявке на поставку
- [`POST` /v1/supply-order/timeslot/get](POST__v1_supply_order_timeslot_get.md) — Интервалы поставки
- [`POST` /v1/supply-order/timeslot/update](POST__v1_supply_order_timeslot_update.md) — Обновить интервал поставки
- [`POST` /v1/supply-order/timeslot/status](POST__v1_supply_order_timeslot_status.md) — Статус интервала поставки
- [`POST` /v1/supply-order/pass/create](POST__v1_supply_order_pass_create.md) — Указать данные о водителе и автомобиле
- [`POST` /v1/supply-order/pass/status](POST__v1_supply_order_pass_status.md) — Статус ввода данных о водителе и автомобиле
- [`POST` /v1/supply-order/details](POST__v1_supply_order_details.md) — Получить подробную информацию о заявке на поставку
- [`GET` /v1/supplier/available_warehouses](GET__v1_supplier_available_warehouses.md) — Загруженность складов Ozon
