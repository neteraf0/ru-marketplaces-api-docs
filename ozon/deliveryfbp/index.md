# DeliveryFBP

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/fbp/act-from/create](POST__v1_fbp_act_from_create.md) — Сгенерировать акт приёмки
- [`POST` /v1/fbp/act-from/get](POST__v1_fbp_act_from_get.md) — Получить статус генерации акта приёмки
- [`POST` /v1/fbp/act-to/create](POST__v1_fbp_act_to_create.md) — Сгенерировать транспортную накладную
- [`POST` /v1/fbp/act-to/get](POST__v1_fbp_act_to_get.md) — Получить статус генерации транспортной накладной
- [`POST` /v1/fbp/archive/get](POST__v1_fbp_archive_get.md) — Получить информацию о завершённой поставке
- [`POST` /v1/fbp/archive/list](POST__v1_fbp_archive_list.md) — Получить список завершённых поставок
- [`POST` /v1/fbp/label/create](POST__v1_fbp_label_create.md) — Cоздать задание на генерацию этикеток
- [`POST` /v1/fbp/label/get](POST__v1_fbp_label_get.md) — Получить статус задания на генерацию этикеток
- [`POST` /v1/fbp/order/get](POST__v1_fbp_order_get.md) — Получить информацию о конкретной поставке
- [`POST` /v1/fbp/order/list](POST__v1_fbp_order_list.md) — Получить список поставок
- [`POST` /v1/posting/fbp/list](POST__v1_posting_fbp_list.md) — Получить список отправлений
