# `POST` /v1/warehouse/rfbs/pause

**Tag:** [BetaMethod](index.md)

**operationId:** `WarehouseRfbsPause`

**Поставить rFBS-склад на паузу**

Скрывает товары склада с витрины. Изменять сток не нужно.

Вы можете оставить обратную связь о работе метода в [комментариях](https://dev.ozon.ru/community/1967-Novye-metody-dlia-ustanovki-pauzy-na-skladakh-rFBS/) в сообществе разработчиков Ozon for dev.

## Parameters

| Name | In | Type | Required | Description |
|------|----|------|----------|-------------|
| `Client-Id` | header | string | ✓ | Идентификатор клиента. |
| `Api-Key` | header | string | ✓ | API-ключ. |

Content-Type: `application/json`
