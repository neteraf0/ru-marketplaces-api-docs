# SellerActions

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/seller-actions/create/discount](POST__v1_seller_actions_create_discount.md) — Создать акцию с механикой «Скидка»
- [`POST` /v1/seller-actions/create/discount-with-condition](POST__v1_seller_actions_create_discount_with_condition.md) — Создать акцию с механикой «Скидка от суммы заказа»
- [`POST` /v1/seller-actions/create/installment](POST__v1_seller_actions_create_installment.md) — Создать акцию с механикой «Беспроцентная рассрочка»
- [`POST` /v1/seller-actions/create/multi-level-discount](POST__v1_seller_actions_create_multi_level_discount.md) — Создать акцию с механикой «Многоуровневая скидка от суммы»
- [`POST` /v1/seller-actions/create/voucher](POST__v1_seller_actions_create_voucher.md) — Создать акцию с механикой «Скидка по промокоду»
- [`POST` /v1/seller-actions/update/discount](POST__v1_seller_actions_update_discount.md) — Обновить акцию с механикой «Скидка»
- [`POST` /v1/seller-actions/update/discount-with-condition](POST__v1_seller_actions_update_discount_with_condition.md) — Обновить акцию с механикой «Скидка от суммы заказа»
- [`POST` /v1/seller-actions/update/installment](POST__v1_seller_actions_update_installment.md) — Обновить акцию с механикой «Беспроцентная рассрочка»
- [`POST` /v1/seller-actions/update/multi-level-discount](POST__v1_seller_actions_update_multi_level_discount.md) — Обновить акцию с механикой «Многоуровневая скидка от суммы»
- [`POST` /v1/seller-actions/update/voucher](POST__v1_seller_actions_update_voucher.md) — Обновить акцию с механикой «Скидка по промокоду»
- [`POST` /v1/seller-actions/products/add](POST__v1_seller_actions_products_add.md) — Добавить товары в акцию
- [`POST` /v1/seller-actions/products/candidates](POST__v1_seller_actions_products_candidates.md) — Получить список доступных для акции товаров
- [`POST` /v1/seller-actions/products/delete](POST__v1_seller_actions_products_delete.md) — Удалить товары из акции
- [`POST` /v1/seller-actions/products/list](POST__v1_seller_actions_products_list.md) — Получить список участвующих в акции товаров
- [`POST` /v1/seller-actions/archive](POST__v1_seller_actions_archive.md) — Перенести акцию в архив
- [`POST` /v1/seller-actions/change-activity](POST__v1_seller_actions_change_activity.md) — Включить или выключить акцию
- [`POST` /v1/seller-actions/list](POST__v1_seller_actions_list.md) — Получить список акций
- [`POST` /v1/seller-actions/voucher/get](POST__v1_seller_actions_voucher_get.md) — Получить файл с промокодами в формате CSV
