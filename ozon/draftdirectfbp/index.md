# DraftDirectFBP

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/fbp/draft/direct/seller-dlv/create](POST__v1_fbp_draft_direct_seller_dlv_create.md) — Создать черновик с доставкой силами продавца
- [`POST` /v1/fbp/draft/direct/seller-dlv/edit](POST__v1_fbp_draft_direct_seller_dlv_edit.md) — Обновить информацию о доставке силами продавца в черновике
- [`POST` /v1/fbp/draft/direct/timeslot/edit](POST__v1_fbp_draft_direct_timeslot_edit.md) — Отредактировать таймслот в черновике
- [`POST` /v1/fbp/draft/direct/timeslot/get](POST__v1_fbp_draft_direct_timeslot_get.md) — Получить список таймслотов для прямой поставки
- [`POST` /v1/fbp/draft/direct/create](POST__v1_fbp_draft_direct_create.md) — Создать черновик заявки на поставку без указания способа доставки
- [`POST` /v1/fbp/draft/direct/delete](POST__v1_fbp_draft_direct_delete.md) — Удалить черновик заявки на поставку
- [`POST` /v1/fbp/draft/direct/product/validate](POST__v1_fbp_draft_direct_product_validate.md) — Проверить список товаров для склада партнёра
- [`POST` /v1/fbp/draft/direct/registrate](POST__v1_fbp_draft_direct_registrate.md) — Перевести черновик в действующую поставку
- [`POST` /v1/fbp/draft/direct/tpl-dlv/create](POST__v1_fbp_draft_direct_tpl_dlv_create.md) — Создать черновик заявки на доставку сторонней транспортной компанией
- [`POST` /v1/fbp/draft/direct/tpl-dlv/edit](POST__v1_fbp_draft_direct_tpl_dlv_edit.md) — Редактировать черновик поставки со способом доставки сторонней транспортной компанией
