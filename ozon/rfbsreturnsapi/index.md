# RFBSReturnsAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v2/returns/rfbs/list](POST__v2_returns_rfbs_list.md) — Список заявок на возврат
- [`POST` /v2/returns/rfbs/get](POST__v2_returns_rfbs_get.md) — Информация о заявке на возврат
- [`POST` /v2/returns/rfbs/reject](POST__v2_returns_rfbs_reject.md) — Отклонить заявку на возврат
- [`POST` /v2/returns/rfbs/compensate](POST__v2_returns_rfbs_compensate.md) — Вернуть часть стоимости товара
- [`POST` /v2/returns/rfbs/verify](POST__v2_returns_rfbs_verify.md) — Одобрить заявку на возврат
- [`POST` /v2/returns/rfbs/receive-return](POST__v2_returns_rfbs_receive_return.md) — Подтвердить получение товара на проверку
- [`POST` /v2/returns/rfbs/return-money](POST__v2_returns_rfbs_return_money.md) — Вернуть деньги покупателю
- [`POST` /v1/returns/rfbs/action/set](POST__v1_returns_rfbs_action_set.md) — Передать доступные действия для rFBS возвратов
