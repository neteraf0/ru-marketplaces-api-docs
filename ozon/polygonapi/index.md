# PolygonAPI

[← Документация Ozon Seller API](../index.md)

## Endpoints

- [`POST` /v1/polygon/create](POST__v1_polygon_create.md) — Создайте полигон доставки
- [`POST` /v1/polygon/bind](POST__v1_polygon_bind.md) — Свяжите метод доставки с полигоном доставки
- [`POST` /v2/polygon/bind](POST__v2_polygon_bind.md) — Связать метод доставки с полигоном
- [`POST` /v1/polygon/delete](POST__v1_polygon_delete.md) — Удалить полигон из области доставки
- [`POST` /v1/polygon/list](POST__v1_polygon_list.md) — Получить список установленных полигонов на метод доставки
- [`POST` /v1/polygon/time/coordinates/update](POST__v1_polygon_time_coordinates_update.md) — Обновить координаты полигона доставки
- [`POST` /v1/polygon/time/set](POST__v1_polygon_time_set.md) — Установить новое время доставки в полигоне
